# Market Intelligence

### AI-Assisted Financial Analytics Platform

**Market Intelligence** is a personal web application project focused on financial-market monitoring, investment analytics, data integration, and clear, responsive dashboards. It combines product design, modern web development, external data sources, and **AI-assisted development (vibe coding)**.

The application offers a dark responsive interface and can be installed on mobile devices as a **Progressive Web App (PWA)**.

## Selected capabilities

- Financial-market dashboard and watchlists
- Investment research tools and market-movement screening
- Asset overview and user-facing analytics
- Market news and publicly available regulatory disclosures
- Institutional filing analysis and economic calendar
- Data ingestion and presentation through external APIs
- Responsive web experience and installable mobile PWA

*Functionality depends on data-source availability and continues to evolve. This project is not investment advice or an automated trading system.*
