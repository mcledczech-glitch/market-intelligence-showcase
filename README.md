## O projektu

**Market Intelligence** je vlastní webová aplikace zaměřená na přehledné zpracování finančních informací, sledování trhů a analytickou podporu investičního rozhodování. Projekt propojuje produktový návrh, moderní webové technologie, práci s externími datovými zdroji a vývoj s pomocí generativní AI (*AI-assisted development / vibe coding*).

Aplikace využívá responzivní tmavé rozhraní a lze ji instalovat na mobilní zařízení jako **Progressive Web App (PWA)**.

## Vybrané funkce

- **Tržní dashboard:** přehled sledovaných finančních trhů, cenových změn a dostupných dat.
- **Investiční analytika:** vlastní watchlist, porovnávání titulů a vyhledávání zajímavých tržních pohybů.
- **Přehled aktiv:** zobrazení a evidence finančních instrumentů v uživatelském rozhraní.
- **Zpravodajství a veřejná data:** práce s tržními zprávami a veřejnými regulatorními oznámeními.
- **Institucionální aktivita:** analytické zobrazení veřejně dostupných hlášení institucí a dalších investorů.
- **Ekonomický kalendář:** přehled významných makroekonomických událostí a zdrojových odkazů.
- **Mobilní použití:** responzivní design a instalovatelná PWA.
- **Datové integrace:** získávání, ověřování a prezentace údajů z externích rozhraní.

> Data jsou zobrazována podle dostupnosti a možností příslušných zdrojů. Některé funkce se průběžně vyvíjejí; aplikace není investičním doporučením ani obchodním systémem.

Tento repozitář slouží **výhradně jako veřejná prezentace projektu**. Neobsahuje produkční zdrojový kód, interní konfiguraci, přihlašovací údaje, API klíče, data uživatelů ani skutečné investiční přehledy.
